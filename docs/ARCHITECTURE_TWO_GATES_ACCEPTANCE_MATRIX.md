## Cross-cutting findings

1. **The autonomous path is demonstrably TEST-only, not a LIVE activation path.** The parser rejects any non-TEST autonomous policy and the Director adapter rejects LIVE compiled audio. The existing LIVE-capable compiled Director methods are separately callable, but are not driven by the autonomous runner.
2. **There is no actual background-worker lifecycle to validate as compliant.** The tested lifecycle is fresh foreground CLI processes and fixture completion, not a queue/worker that sleeps, wakes, renews a lease, or resumes work without a chat/CLI continuation. `ATM-P1-02` and `ATM-P1-03` are the critical architectural gap rather than credential availability.
3. **Blocking I/O is on the async path.** This is a concrete throughput/reliability gap even with valid providers: FFmpeg work runs synchronously inside an async final-QA method.
4. **Caches and leases are class-presence only.** Neither is wired into real TTS/render/worker call paths; tests prove local behavior, not production use.
5. **The test suite could not be executed in this audit environment:** `python -m pytest ...` returned `No module named pytest`. The references above are inspected test references, not a claimed test pass.

## Prioritized independent vertical slices

### Slice A — durable worker, lease, and non-blocking render

**Exact files:**
- `src/hybrid/worker.py` (new)
- `src/hybrid/lease.py`
- `src/hybrid/render.py`
- `src/hybrid/autonomous.py`
- `src/hybrid/autonomous_cli.py`
- `tests/unit/test_hybrid_worker_lifecycle.py` (new)
- `tests/unit/test_episode_lease.py`
- `tests/unit/test_hybrid_render.py`

**Acceptance:** a worker claims one persisted TEST/LIVE-appropriate work item under `EpisodeLeaseStore`, renews before TTL expiry, rejects stale fencing tokens, resumes a crash checkpoint without a second submit, and records a next-action state. Rendering is dispatched through a bounded worker/thread boundary so a second eligible work item progresses while FFmpeg is active. CLI/chat only enqueue or report status; they do not own continuation. Tests cover two workers, crash/restart, lease expiry during render, and no duplicate provider call.

### Slice B — cache-backed semantic remediation and unified metrics

**Exact files:**
- `src/hybrid/autonomous.py`
- `src/hybrid/compiled.py`
- `src/hybrid/revision.py`
- `src/providers/tts/edge_tts_provider.py`

- `tests/unit/test_autonomous_two_gate.py`
- `tests/unit/test_hybrid_operational_pipeline.py`
- `tests/unit/test_semantic_remediation.py` (new)

**Acceptance:** TTS and scene render call sites look up/store verified cache artifacts with the complete input contract; restart reuses a valid segment/scene and changes to voice, semantic timing, motion, or config miss the cache. QA FAIL must use a closed semantic code and a deterministic successor payload that binds predecessor hash and preserves nonfailed constraints; generic correction suffixes are rejected. One idempotent metrics event links route/model usage, cache tokens, latency, executor request ID, and billing state without treating unknown billing as zero. Tests cover cache tamper, semantic-code-to-successor mapping, restart, duplicate observation, and unknown billing.
