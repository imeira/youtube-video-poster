# Script contract

Cada roteiro é `script.json`, com público `{min_age: 6, max_age: 10}`, segmentos tipados e fontes por paráfrase bíblica. `family_reflection` não é apresentada como fato bíblico. O encerramento declara 3–5 segundos e `burn_subtitles: false`.

O TTS é bloqueado por QA se houver segmentos sem fonte, público incorreto, fechamento inválido ou linguagem infantil insegura.
